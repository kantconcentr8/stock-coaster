# P2.4 — Scroll, Zoom, Gesture Suppression & In-App Browser Notes

- **Active gameplay (`running` / `countdown`):**
  - `body.is-playing` sets `overscroll-behavior: none`, `user-select: none`, `-webkit-user-select: none`, `-webkit-touch-callout: none`, and `touch-action: none`.
  - `#game` and `#touch-controls` also set `touch-action: none` so double-tap zoom, pinch-zoom, and pull-to-refresh are suppressed while playing.
- **Menus & Results (`intro`, `paused`, `results`):**
  - `body.is-playing` is removed automatically by `app.ts` whenever the state machine leaves `running`/`countdown`.
  - `.modal-card` allows vertical scroll (`overflow-y: auto; max-height: 86dvh`) so longer debriefs and results remain scrollable on small screens.
- **Accessibility:**
  - `index.html` `<meta name="viewport">` does **not** set `user-scalable=no` or `maximum-scale=1`, preserving browser zoom on text screens.
- **In-app browser hardening (`src/ui/inAppBrowser.ts`):**
  - Detects X/Twitter, Instagram, Facebook, LinkedIn, and TikTok WebViews.
  - Prepends a non-blocking banner with a `Copy link` button and `✕` dismiss button on the intro card.
